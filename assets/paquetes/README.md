# Fotos de los paquetes

Una imagen por destino, nombrada con el `id` del paquete en `index.html`:

```
riviera-maya.jpg    curazao.jpg       bayahibe.jpg
aruba.jpg           porto-de-galinhas.jpg
punta-cana.jpg      cancun.jpg        florianopolis.jpg
san-andres.jpg      buzios.jpg
```

Formato: JPG, relación 16:10, 780×488 px (2x del ancho de card).

Mientras el archivo no exista, la card muestra un degradado de fondo en
lugar de una imagen rota, así que se puede ir completando de a una.
